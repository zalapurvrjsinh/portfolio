# Personal Portfolio Website

A clean, responsive personal portfolio website showcasing my academic background, technical skills, and software development projects.

## Technologies Used
- **HTML5** (Semantic structure: header, nav, section, footer, form)
- **CSS3** (Custom properties, Flexbox, CSS Grid, hover transitions, media queries)
- **JavaScript (ES6)** (Dark mode toggle, mobile navigation menu, client-side form validation)
